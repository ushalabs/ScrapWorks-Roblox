# Release Notes

## v0.1.0 — Phase 0: field-test foundation

- Initial stylized 3D scrapyard and refinery.
- Three materials, nine scrap nodes, bag capacity five.
- Interaction-based collection and refinery selling.
- Owner-verified collection and $120 sale.

**Installation:** import only `Scrapworks_Demo_v1.rbxmx` under Workspace.

## v0.2.0 — Phase 1: industrial expansion

- Freight annex and additional scrap nodes.
- Six material types, 12-item inventory, 2.4-second refinery cycle.
- Shared inventory and economy modules, new HUD.
- Owner-verified 12-item sale and $387 credited.

**Installation:** import `Scrapworks_Demo_v1.rbxmx` then `Scrapworks_Phase1_Upgrade.rbxmx`.

## v0.3.0 — Phase 2: machinery progression

- Hydraulic Compactor ($200), Optical Sorter ($650), Induction Smelter ($1,600).
- Server-side purchase validation and processing bonuses 1.20×, 1.35×, 1.60×.
- Upgrades shop and original inventory-counter fix.
- User reports the upgrade working in a Studio session.

**Installation:** import Phase 0, Phase 1, then Phase 2 models into the same Workspace.

## v0.3.5 — Phase 2.5: visual workshop overhaul (pre-release test)

- Distinct model detailing for all six salvage material categories across 24 nodes.
- Refinery frame/conveyor detailing and machine-specific production geometry.
- Machine-bay lights and environmental signage.
- Styling layer for existing Phase 1 and Phase 2 HUDs, preserving their event listeners.
- No economy, price, or gameplay changes intended.

**Installation:** import all four models in version order. Visual changes are validated structurally, but a Roblox Studio playtest is required.
